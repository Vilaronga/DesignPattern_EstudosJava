# Projeto Design Patterns

Projeto desenvolvido com o intuito de demonstrar em prática, o conhecimento adquirido sobre Design Patterns utilizando Java durante o bootcamp Santander - DIO.

## Padrões que forma utilizados

### Strategy
Utilizado para representar diferentes formas de pagamento.

### Observer
Utilizado para notificar componentes quando o status
do pedido é alterado.

## Tecnologias

- Como opção apresentada no desafio, optei por realizar em Java puro.

## Exemplos

O projeto demonstra pagamentos via:
- Pix
- Cartão de crédito
- Cartão de débito

Também demonstra notificações "automáticas" quando sofre alteração do status
do pedido.
